# Master-Prompt Mapping

## Architektur / Stack
- Astro + TypeScript strict
- Tailwind CSS Build-Basis
- GSAP + ScrollTrigger
- Lenis nur auf Desktop / feinem Pointer
- Kein React, Vue, Angular oder Three.js
- Server-Route für Resend-Kontakt

## Design
- Premium, ruhig, schwarz / orange / warmes Off-White
- DOM-basierte 2.5D-Hero-Szene statt schwerem WebGL
- Fullscreen-/Sticky-Start nach Video-Referenz, aber ohne dominantes Hausmotiv
- Floating-Layer-Gefühl aus der zweiten Referenz, bewusst reduziert
- Leistungsblöcke in Schwarz / Papier / Orange nach Screenshot-Referenz

## Animation
- Hero-Depth und kontrollierter Scroll-Fade
- dezente Reveal-Animationen
- leichte Pointer-Tiefe nur Desktop
- keine Cursor-Ersetzung
- Reduced-Motion-Fallback

## Projekt-Check
- lokale automatische Einordnung: Website / Webapp / App / internes Tool / maßgeschneiderte Software
- Funktionsvorschläge
- Projektgröße
- grober Zeitraum
- Budgetfeld vorbereitet, aber ohne erfundene Preise
- schematisches Wireframe
- kein sichtbarer Tech-Stack

## SEO / GEO / AEO
- Title / Description / Canonical
- OpenGraph / Twitter-Basis
- Organization JSON-LD
- robots.txt / sitemap.xml / 404
- llms.txt als sachliche Zusatzdatei
- semantische H1/H2/H3-Struktur und klare Antworttexte

## Datenschutz / Sicherheit
- keine Tracker, externen Fonts oder Marketingpixel
- Projekt-Check lokal im Browser
- Resend serverseitig
- Zod-Validierung, Honeypot, Same-Origin-Prüfung, Rate-Limit-Basis
- Sicherheitsheader in Middleware
- Datenschutz / Impressum mit klaren TODO-Platzhaltern
- LEGAL_TODO.md

## Accessibility
- Skip-Link
- semantische Landmarks
- sichtbare Fokuszustände
- echte Labels
- aria-live Statusmeldungen
- Touch-Ziele
- Responsive Layout
- Reduced Motion
